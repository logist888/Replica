# Методология первой версии (v1)

Цель: бесплатный публичный тест уровня английского, результаты бесплатны, без методиста на старте.
Критерий выбора: каждый компонент должен быть либо подтверждён по первоисточнику как разрешённый для бесплатного публичного использования, либо исключён.
Это не юридическая консультация. Условия «как я их прочитал» помечены.

## 1. Что можно использовать (проверено по первоисточникам 2026-11-02)

| источник | что даёт | условия по первоисточнику | решение |
| --- | --- | --- | --- |
| Схема ca-MST + модель Раша | структура теста, калибровка, оценка | научные методы, не объект права; EF описывает свою реализацию, не владеет методом | **используем**, реализация своя (`engine/`) |
| CEFR-J Vocabulary Profile 1.5 (7799 слов A1–B2) | уровни слов | README репозитория: «research and commercial purposes with no charge, provided that you cite the dataset properly»; правообладатель Tono Laboratory, TUFS. Страница cefr-j.org для Wordlist 1.6: коммерческое использование с указанием источника; часть пункта про «supervision» читал в переводе с японского | **используем**, с цитированием; одно письмо правообладателю для подтверждения |
| Octanove Vocabulary Profile C1/C2 (2136 слов) | уровни слов C1–C2 | CC BY-SA 4.0 | **используем**; производные списки слов публикуем под CC BY-SA 4.0 |
| CEFR-J Grammar Profile | грамматика по уровням | на странице загрузки лицензии нет, есть только просьба цитировать | **не используем в v1**, запрашиваем разрешение |
| NGSL (частотный список) | частотность, база для заданий | сайт: «All lists are released under Creative Commons and may be used commercially», основной список CC BY-SA 4.0 | **используем** для частотных подсказок и подбора текстов; атрибуция и share-alike |
| Wikipedia, текст | тексты для чтения | CC BY-SA 4.0: указать авторов, указать изменения, лицензировать производное так же | **используем** как источник текстов для чтения |
| Project Gutenberg, тексты | тексты для чтения, C-test | публичное достояние в США; товарный знак Gutenberg требует условий, если название используется: достаточно убрать упоминания | **используем**, убирая упоминание Gutenberg; вне США проверять статус произведения |
| LibriVox, аудио | аудио для аудирования | «recordings are in the public domain… you don’t need permission», но по праву США | **используем** для некоторых заданий; проверять страну аудитории |
| Own content (свои тексты и запись) | основное содержание | ваши права | **основной источник** |
| Метод yes/no словаря | формат теста слов | метод общеизвестен; программа Lognostics V_YesNo бесплатна «in exchange for critical assessments», о повторном использовании слов ничего не сказано | метод **используем**, их слова и программу **нет** |
| Метод C-test | формат заданий | метод общеизвестен, но подтвердить по авторитетному источнику не удалось | метод **используем** осторожно, формулу «повреждения» зафиксировать самим |
| English Placement Suite (код MIT, задания CC BY-NC 4.0) | образец структуры, возможный тестовый банк | CONTENT-LICENSE.md: нельзя использовать в коммерческих целях | **только для прототипа**; в боевой банк нет, если есть хоть малейший шанс монетизации |
| mirt (R) | калибровка | GPL-3 | **не используем**; своя реализация Раша |

Не подтверждено, поэтому **не используем**, пока не проверено: LexTALE (страница не открылась), списки Nation (на страницах нет условий), Common Voice (страница не показала лицензию), English Vocabulary Profile (страница пуста), дескрипторы Совета Европы (доступ запрещён), CEFR-SP (лицензия не указана), голоса Piper TTS (лицензия каждого голоса не проверена), catR, mirtCAT, py-irt, руководство Duolingo.

Не используем по существу: банк заданий EF SET, их параметры, пороги и таблицы. Корреляции с TOEFL и IELTS EF — только как идея проверки, не как наши данные.

## 2. Что означает «отдавать результаты бесплатно» для лицензий

Мой разбор, не юридический вывод:
- Лицензии с share-alike (Wikipedia, NGSL, Octanove) требуют, чтобы **производные материалы, которые вы распространяете**, шли под той же лицензией. Показ текста пользователю в тесте — распространение. Значит, адаптированные из Wikipedia тексты заданий и списки слов из Octanove публикуются как CC BY-SA 4.0. Это не заставляет открывать весь банк, но тексты, которые видят тестируемые, должны нести эту лицензию и атрибуцию.
- Ваши собственные задания, калибровочные параметры, секретные зерна формы и код можно держать закрытыми. Открытая лицензия на код — ваше решение.
- Практическое следствие для безопасности: тексты из BY-SA легко найти в сети; задания на них защищает только ротация и калибровка, не секретность. Для критичной части (чтение и вопросы) лучше писать свои тексты.
- Лицензия NC (English Placement Suite) для бесплатного продукта без рекламы формально может подойти, но граница «некоммерческого» размыта, поэтому я бы её не закладывал в основу.

## 3. Состав первой версии

Три части, всего около 45 минут. Всё на английском, на русском только памятка перед стартом.

| часть | формат | объём | время | как оценивается |
| --- | --- | --- | --- | --- |
| 1. Vocabulary | yes/no с псевдословами | 60 карточек: 44 настоящих слов по уровням (A1 4, A2–C2 по 8) и 16 псевдослов | 4 мин | поправка на угадывание (h−f)/(1−f); при доле «знаю» на псевдослова выше 40% ответы не засчитываются |
| 2. Reading | 3 стадии, 8 заданий в модуле, 24 задания; ответы на несколько вопросов к коротким текстам | 24 | 20 мин | Раш, EAP |
| 3. Listening | то же, аудио | 24 | 20 мин | Раш, EAP |

Что говорит симуляция (`engine/simulate.py`, модель Раша, 3000 смоделированных людей, theta ~ N(0, 1.3)):

| заданий в модуле | всего | RMSE, шум калибровки 0 / 0,3 / 0,5 | RMSE фиксированной формы той же длины |
| --- | --- | --- | --- |
| 6 | 18 | 0,51 / 0,52 / 0,57 | 0,59–0,63 |
| 8 | 24 | 0,45 / 0,45 / 0,46 | 0,54–0,56 |
| 10 | 30 | 0,40 / 0,40 / 0,39 | 0,47–0,52 |

Выводы из симуляции:
- адаптивная схема точнее фиксированной формы на 0,1–0,15 логита при той же длине, то есть заметно;
- ошибка калибровки до 0,5 логита почти не ухудшает оценку людей, потому что ошибки заданий усредняются;
- 24 задания на навык дают заявленную стандартную ошибку около 0,45, это сопоставимо с целью, которую EF называет для своего 50-минутного теста (не больше 0,45).

Чего симуляция НЕ показывает (поэтому реальная точность хуже):
- в вариантах с выбором ответа есть угадывание (нижняя граница 25%), а модель Раша его не учитывает;
- вопросы к одному тексту зависимы, эффективное число заданий меньше;
- настоящие задания не идеально подчиняются модели Раша;
- классификацию по CEFR симуляция не проверяет: связь шкалы с уровнями неизвестна (см. раздел 5).
Поэтому в v1 закладываю 24 задания как минимум и пересчёт после пилота; если реальная SE выше 0,55, увеличить до 10 заданий на модуль.

## 4. Банк заданий

Размер для запуска v1 с одной панелью: 8 модулей × 8 заданий = 64 на навык; с запасом 50% на выбраковку после пилота около 100 на навык, то есть около 200 на два навыка плюс слова из списков. Для ротации нескольких форм позже: около 300 на навык.

Откуда:
- **Reading.** Свои тексты 80–250 слов на уровни A1–C2, часть на основе Wikipedia или Gutenberg с атрибуцией. Вопросы: 3–4 на текст, 4 варианта. Черновики можно готовить с помощью Claude, но каждое задание проверяет человек со знанием английского, а правовой статус текста, созданного ИИ, в вашей юрисдикции нужно уточнить.
- **Listening.** Свои короткие записи (30–90 секунд) либо записи LibriVox (по праву США). Синтез речи не используем, пока не проверена лицензия конкретного голоса.
- **Vocabulary.** Автоматически из CEFR-J и Octanove, `engine/vocab_form.py`. Псевдослова нуждаются в просмотре человеком: на реальных данных генератор выдал `wring`, а это настоящее английское слово. Словарь для отсева в окружении не нашёлся, нужно подключить свой (`--dictionary`).
- Каждое задание заносится в `content_sources` с лицензией; в боевой банк идут только записи с `commercial_use_ok = true`.

## 5. Калибровка и уровни CEFR без методиста

Симуляция восстановления сложности заданий по пилоту (150 заданий, 40 на человека):

| человек в пилоте | RMSE сложности, логитов |
| --- | --- |
| 100 | 0,56 |
| 200 | 0,46 |
| 300 | 0,39 |
| 500 | 0,24 |

План:
1. Пилот не меньше 300 человек (для ошибки около 0,4 логита), лучше 500; задания распределены с пересечением, часть общих «якорных».
2. Калибровка Раша своим кодом (`engine/rasch.py`), удаление заданий с плохой подгонкой.
3. **Границы уровней.** Проблема: калибровка даёт шкалу сложности, но не говорит, где проходит B1 или B2. Без экспертной панели честный путь такой: (а) участники пилота по желанию вводят результат известного внешнего теста (IELTS, TOEFL, Cambridge, Duolingo) и мы сопоставляем; (б) сверка со словарными уровнями CEFR-J; (в) двое-трое преподавателей оценивают небольшую подвыборку.
4. До набора 150 участников с внешним якорем **публикуем только диапазон** («B1–B2»), не одну букву, и подпись «provisional estimate».

Это слабое место продукта. Цена ошибки: смещение границ на пол-уровня. Допустимо для самодиагностики, недопустимо для решений о найме или поступлении.

## 6. Что публиковать

- Результат пользователю: баллы, диапазон уровня, пояснение, что оценка предварительная. Бесплатно.
- Открыто: описание методики, отчёт по пилоту, списки слов (CC BY-SA 4.0), код движка при желании.
- Закрыто: банк заданий в той части, что свои, параметры, зёрна форм.

## 7. Риски и пробелы

- **Контент** — основной объём работы: около 200 заданий с проверкой человеком.
- **Лицензии**: CEFR-J Wordlist — получить подтверждение правообладателя; Grammar Profile — разрешение; share-alike для адаптированных текстов.
- **Нет прокторинга**: результат можно получить с помощью. Формулировать как диагностику.
- **Уровни CEFR** без экспертной панели условны. Лучшее смягчение — внешний якорь и диапазоны.
- Полные Terms efset.org не прочитаны целиком; юристу.
- Условия: если появится методист или университетский партнёр, границы уровней и контроль качества заменить его процедурой.

## 8. Состав репозитория

```
engine/rasch.py        калибровка JML и оценка EAP, stdlib
engine/mst.py          панель из трёх стадий, маршрутизация по оценке
engine/simulate.py     симуляция точности и пилота
engine/vocab_form.py   форма yes/no из CEFR-J и Octanove, подсчёт балла
engine/tests/          15 тестов
```
Запуск тестов: `cd engine && python3 -m unittest discover -s tests`.
Данные CEFR-J и Octanove в репозиторий не кладём: скачать из https://github.com/openlanguageprofiles/olp-en-cefrj.
Атрибуция при использовании: «The CEFR-J Wordlist Version 1.5. Compiled by Yukio Tono, Tokyo University of Foreign Studies.»; Octanove Vocabulary Profile C1/C2 под CC BY-SA 4.0.
