# План тестирования пилота

Объект: `app/` (Next.js 16 + Postgres). Тестируем только собственное приложение. Оригинал (EF SET) не трогаем.
Среда: локальный Postgres 16 (порт 5544), приложение `next start` на порту 3100, Chromium из `/opt/pw-browsers`.

Потоки пилота (в рекон-карте F01, F02, F05; остальные потоки оригинала в пилот не входят):
- F01 Пройти тест: лендинг, согласие, часть 1 (словарь), часть 2 (чтение), результат.
- F02 Открыть результат по ссылке.
- F05 Выгрузка данных администратором (заменяет «найти сертификат»).

## F01 Прохождение

| № | тип | случай | ожидаем |
| --- | --- | --- | --- |
| F01-H1 | счастливый | полный путь с мобильного экрана 390 px | 60 слов, 10 текстов, страница результата, в базе 60+30 ответов, сессия done |
| F01-E1 | граничный | старт без галочек | кнопка неактивна; API без согласия отвечает 400 |
| F01-E2 | граничный | двойной клик по «Yes» | засчитывается один ответ, счётчик слов +1 |
| F01-E3 | граничный | двойной клик по «Next text» | один запрос, переход на один текст |
| F01-E4 | граничный | перезагрузка страницы посреди части 1 | возврат на экран согласия, без ошибок; старая сессия остаётся незавершённой |
| F01-E5 | граничный | обрыв сети при отправке последнего слова | понятное сообщение, после возврата сети повтор работает |
| F01-E6 | граничный | эмодзи, длинные строки и кавычки в полях анкеты | сохраняются обрезанными, без 5xx |
| F01-E7 | граничный | только клавиатура: галочки, кнопки, радиогруппа | всё достижимо, фокус виден |
| F01-E8 | граничный | экран 390 px: нет горизонтальной прокрутки, цели касания ≥ 44 px | да |
| F01-E9 | граничный | устаревшая сессия (более 3 часов) | ответ 404, понятное сообщение |
| F01-N1 | отрицательный | /api/vocab без всех ответов | 400 |
| F01-N2 | отрицательный | /api/vocab повторно | 409 |
| F01-N3 | отрицательный | /api/reading до части 1 | 409 |
| F01-N4 | отрицательный | /api/reading: неверный выбор (7), чужой вопрос, пустой список | 400 |
| F01-N5 | отрицательный | /api/finish до чтения; повторно после | 409; затем та же ссылка |
| F01-N6 | отрицательный | повторная отправка ответа на тот же вопрос | первый ответ сохраняется |
| F01-N7 | отрицательный | ответы с ключами не уходят клиенту | в ответах API нет полей answer/real |
| F01-N8 | отрицательный | старт 31 раз с одного IP | 429 после 30 |

## F02 Результат по ссылке

| № | тип | случай | ожидаем |
| --- | --- | --- | --- |
| F02-H1 | счастливый | открыть ссылку после завершения | диапазон уровня, пометка «Provisional» |
| F02-E1 | граничный | токен неправильной длины / не hex | 404 |
| F02-E2 | граничный | токен незавершённой сессии | 404 |
| F02-E3 | граничный | чужой токен (угадывание) | 404, перебор недопустим по длине токена 128 бит |
| F02-E4 | граничный | страница не индексируется | meta robots noindex |

## F05 Администратор

| № | тип | случай | ожидаем |
| --- | --- | --- | --- |
| F05-H1 | счастливый | выгрузка sessions и responses с токеном | CSV, только завершённые сессии |
| F05-N1 | отрицательный | без токена, с неверным токеном, с токеном другой длины | 404 |
| F05-E1 | граничный | отрицательные числа и формулы в полях | числа не искажены, формулы нейтрализованы |
| F05-E2 | граничный | неизвестный kind | 404 |

## Сквозные
- A11y: сканирование axe на всех экранах (лендинги, приватность, согласие, слово, чтение, результат).
- Консоль браузера без ошибок, ни одного ответа 5xx.
- Приватность: IP не хранится, User-Agent не длиннее 200 символов.

## Ручная проверка (не автоматизируется здесь)
- чтение с экранным диктором (VoiceOver, TalkBack, NVDA);
- реальные устройства iOS Safari и Android Chrome;
- читаемость русского лендинга носителем языка и юридических текстов юристом;
- работа за прокси провайдера: заголовок X-Forwarded-For.
