План тестирования пилота

Объект: app/ (Next.js 16 + Postgres). Тестируем только собственное приложение. Оригинал (EF SET) не трогаем. Среда: локальный Postgres 16 (порт 5544), приложение next start на порту 3100, Chromium из /opt/pw-browsers.

Потоки пилота (в рекон-карте F01, F02, F05; остальные потоки оригинала в пилот не входят):

  • F01 Пройти тест: лендинг, согласие, часть 1 (словарь), часть 2 (чтение), результат.
  • F02 Открыть результат по ссылке.
  • F05 Выгрузка данных администратором (заменяет «найти сертификат»).

F01-E1 граничный старт без галочек кнопка неактивна; API без согласия отвечает 400

F05 Администратор

№ тип случай ожидаем
F05-H1 счастливый выгрузка sessions и responses с токеном CSV, только завершённые сессии
F05-N1 отрицательный без токена, с неверным токеном, с токеном другой длины 404
F05-E1 граничный отрицательные числа и формулы в полях числа не искажены, формулы нейтрализованы
F05-E2 граничный неизвестный kind 404

Сквозные

  • A11y: сканирование axe на всех экранах (лендинги, приватность, согласие, слово, чтение, результат).
  • Консоль браузера без ошибок, ни одного ответа 5xx.
  • Приватность: IP не хранится, User-Agent не длиннее 200 символов.

Ручная проверка (не автоматизируется здесь)

  • чтение с экранным диктором (VoiceOver, TalkBack, NVDA);
  • реальные устройства iOS Safari и Android Chrome;
  • читаемость русского лендинга носителем языка и юридических текстов юристом;
  • работа за прокси провайдера: заголовок X-Forwarded-For.
