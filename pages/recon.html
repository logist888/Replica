Recon map: EF SET (web)

Срез: прохождение сертифицирующего теста «Чтение и аудирование» (2 навыка, 50 мин), страница результата, публичный сертификат, практический тест (20 вопросов). Для кого: будущий собственный продукт; рынок и язык интерфейса не определены. Дата: 2026-11-02 Статус: только публичные страницы (16 страниц прочитаны). Сам тест не проходился, внутренние экраны теста НЕ видены. Всё, что про них, помечено как вывод или предположение.

Core loop

Человек бесплатно проходит адаптивный онлайн-тест английского, получает балл 0-100, привязанный к уровню CEFR, и публичную ссылку на сертификат, которую добавляет в резюме или LinkedIn.

Flows

F01 Пройти сертифицирующий тест (2 навыка)
    S01 -> S03 -> S08 -> S09 -> S10/S11 (адаптивно, до конца) -> S13 -> S14
    happy path clicks: не определено (тест не пройден)
    edge: обрыв сессии (результат теряется, продолжить нельзя), повторная попытка раньше 90 дней, возраст младше 16, не Chrome, нет звука

F02 Получить и поделиться сертификатом
    S13 -> S14 -> S15 / S17
    edge: обновление сертификата после пересдачи (старый заменяется новым)

F03 Практический тест
    S01 -> S16 -> результат (процент из 20)
    edge: без сертификата, неограниченные пересдачи

F04 Корпоративная ссылка
    custom-ссылка от школы или работодателя -> F01, результат уходит организации
    (по FAQ и странице 4-skill; детали неизвестны)

F05 Найти сертификат
    S18 -> S14

Inferred data model

User         id, email, name, age_confirmed, locale
             evidence: Terms (регистрация, возраст 16+), S08
             confidence: medium

TestSession  id, user_id, test_type (4skill | 2skill | practice), started_at, finished_at,
             status (in_progress | completed | cancelled), ability_estimate
             evidence: FAQ (фатальная ошибка отменяет сессию, возобновления нет)
             confidence: high по статусам, guess по полям

Item         id, skill (reading | listening), content, options, correct, difficulty (калибровка IRT), cefr_target
             evidence: FAQ (претест, калибровка, «no answer key»)
             confidence: guess (структура), high (факт существования банка)

Response     session_id, item_id, answer, correct, time_ms, served_order
             evidence: адаптивность по FAQ
             confidence: medium

Result       session_id, skill, score_0_100, cefr_level
             evidence: FAQ («score for each skill»)
             confidence: high

Certificate  id (публичный токен), user_id, session_id, issued_at, updated_at
             evidence: пример cert.efset.org/h4T3oX; FAQ: пересдача обновляет сертификат
             confidence: high

Attempt limit: не более 1 сертифицирующей сессии на 90 дней (FAQ) — правило, не сущность.

Связи: User 1-n TestSession; TestSession 1-n Response; Response n-1 Item; TestSession 1-n Result; User 1-1 Certificate (обновляется).

Расхождения в публичных данных

  • Шкала: /english-score/ даёт pre-A1 0-20, A1 21-30; /cefr/ даёт A1 1-30 без pre-A1. A2 31-40, B1 41-50, B2 51-60, C1 61-70, C2 71-100 совпадают.
  • Время: Wikipedia: 25 минут на чтение и 25 на аудирование. Сайт этого не подтверждает.
  • Число вопросов в сертифицирующих тестах нигде не указано.

Size

Экранов 19 (из них внутри теста не видел 5), потоков 5, сущностей 6. Сложные части: (1) банк заданий и его калибровка, (2) адаптивный алгоритм (IRT + контроль экспозиции), (3) аудио и защита от копирования/прохождения без прокторинга. Размер движка и интерфейса без контента: M. Вместе с валидным контентом: L и выше, определяется в основном не кодом.

Методология: можно ли взять за основу

Известно

  • EF создал тест с консультантами: Lyle Bachman (дизайн), Ric Luecht и John Willse (психометрия), Mari Pearlman (разработка). Источник: FAQ.
  • Заявлено: претестирование на сотнях тысяч учащихся, формальное standard setting, адаптивный дизайн, соответствие стандартам APA/NCME 2014 (последнее со страницы EF на французском, найдено через поиск).
  • Описание в открытом доступе есть только в EF SET Academic Report (PDF), который я не читал.
  • Явной открытой лицензии на методику и задания нет. «Free» относится к цене. © Signum International AG.

Вывод

  • Идеи (адаптивное тестирование, IRT, привязка к CEFR, шкала 0-100) общие, они принадлежат науке, а не EF. Использовать их можно.
  • Задания, аудио, калибровочные параметры, таблицы перевода баллов в уровни как данные EF использовать нельзя. У вас нет права ни на скачивание, ни на воспроизведение.
  • Пересказ методики из Academic Report допустим для понимания, но само «калибровать как у EF» невозможно без их данных.

Предположение

  • Что копирование контента запрещено Terms: полученный текст Terms такого пункта не содержит, но он мог быть усечён. Авторское право действует и без пункта. Проверить текст целиком и, если нужен прямой ответ, юристу.

Вывод по рекомендации

Методологию EF брать за основу как готовый продукт нельзя. Брать можно открытые научные подходы и открытые материалы по CEFR. Без методиста безопасный путь — тест нижнего риска (размещение/диагностика, а не «сертификат»), с честной формулировкой «ориентировочный уровень».

Бесплатные и открытые опоры

опора что даёт лицензия или условие статус проверки
CEFR-J (vocabulary и grammar profile), https://github.com/openlanguageprofiles/olp-en-cefrj списки слов и грамматики по уровням CEFR по странице проекта: свободно для исследований и коммерции при указании источника; правообладатель Tono Laboratory, TUFS прочитано через поиск; проверить на cefr-j.org до коммерческого использования
Octanove Vocabulary Profile (C1/C2) в том же репозитории слова C1/C2 CC BY-SA 4.0 то же; обязательства share-alike
DIALANG (Lancaster), https://wp.lancs.ac.uk/ltrg/?p=853 бесплатная система диагностики по CEFR, 14 языков, модель самооценки это готовый сервис, лицензия на контент неизвестна как образец структуры, не как источник заданий
Duolingo English Test, Technical Manual (Cardwell et al., 2023) и Settles et al. 2020 (TACL) открытое описание методики: yes/no vocabulary, C-test, IRT, адаптивность публикации открыты для чтения; задания DET закрыты методика читается, контент не берём
C-test автоматически генерируемые задания (вырезается вторая половина каждого второго слова), хороший прокси общего уровня метод общеизвестен, тексты нужны свои или с открытой лицензией метод; тексты брать из CC-лицензированных источников
IRT и CAT (открытые библиотеки) расчёт сложности, адаптивный подбор стандартные научные методы реализуемо без методиста на уровне 1-2 параметров
Словарь CEFR-уровней Council of Europe описания дескрипторов условия повторного использования не нашёл юридически не подтверждено, смотреть coe.int
English Placement Suite (Product Hunt: «open-source, adaptive A1–C2.2+») возможная готовая основа лицензия и репозиторий не проверены гипотеза, проверять напрямую

Что рекомендую дальше

  1. Читать EF SET Academic Report и исследования корреляции (PDF, публичные) как описание методики, не копируя таблицы.
  2. Считать вашим продуктом не клон сертификата, а диагностический тест на открытой основе: CEFR-J словари, C-test и yes/no vocabulary в качестве быстрых форматов, IRT калибровка по вашим пилотным данным.
  3. Обязательно на ранней стадии: пилот 200-300 человек и сверка с внешним тестом, иначе уровни CEFR будут ориентировочными. Это вопрос честности формулировок на сайте.
  4. Следующий шаг пакета: /replica-architect на этой recon-карте с исключением банка заданий (он заменяется вашей системой генерации заданий).
